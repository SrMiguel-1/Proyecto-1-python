# Proyecto-1-python
trabajo de clase
Es de nuestro agrado presentar tal sublime obra de código.
Nuestro código funciona para registrar: clientes, instructores, vehículos y citas. Todo para solucionar la problemática planteada por DriveSafe.
Nuestro código cuenta con: .json para guardado de datos haciendo posible su uso sin complicaciones y pérdida de información valiosa.
Esta versión aun es muy temprana pero si es del agrado del cliente (Profesor), se podrá actualizar a una mejor que cuente con más características útiles
para esta empresa.
En otros aspectos, contamos con distintas funcionalidades como ver los clientes registrados, vehículos registrados y los demás datos anteriormente mencionados. por ende también tendrá un control de las citas y podrá ver la disponibilidad de los vehículos e instructores.
